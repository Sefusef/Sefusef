# Welearn & Educational Suite 📚🤖

Welcome to the official repository hub for **Welearn**, founded and developed by **Seif Rashidi Malogo**. This organization and repository collection bridges pedagogical examination standards with mobile engineering, delivering high-performance tools for students, teachers, and academic authorities.

---

## 🚀 Core Applications & Products

### 1. Wonderz Learn (Student Assistant Suite)
An all-in-one learning companion application built for students to study anywhere, featuring:
* **Free Notes Engine:** Curated study guides covering core subjects like Computer Fundamentals, hardware/software architectures, and sciences.
* **Class Videos Hub:** Integrated video course player for subjects ranging from languages and mathematics to computer science (Microsoft Word, Excel, Python).
* **Peer & AI Chat Room:** Real-time public and private messaging with code-sharing support and syntax highlighting.
* **Mobile Python Editor & Console:** A built-in code runner allowing students to write, test, and execute Python scripts directly on their mobile devices.

### 2. TimePro (`com.timetable.timepro`)
An advanced timetable and time-management companion designed specifically for schools:
* Precise background alarm managers and notification schedulers.
* Silent student mode routines for classrooms.
* Expandable list management and seamless AdMob monetization integration.

### 3. Lesson Plan & Smart Exam Engine
A hybrid web-and-mobile tool tailored for primary school curriculum developers and teachers:
* Generates NECTA-compliant lesson plans and automated class registers.
* Powered by OCR vision models and the Gemini AI API to parse handwritten mark sheets, evaluate student scripts, and handle broadsheet reporting.

## 🛠️ Tech Stack & Architecture

* **Mobile Development:** Android SDK, Kotlin, Java, Gradle build configurations.
* **Hybrid Interfaces:** WebView optimization, HTML5, Tailwind CSS, JavaScript bridges.
* **AI & Cloud Integration:** Gemini API integration, vision-based text extraction.
* **Monetization & Utilities:** Google AdMob SDK, SQLite storage, SheetJS data processing.
